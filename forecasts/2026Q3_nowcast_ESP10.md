# 超早期推計の記録：2026年7-9月期 内閣府GDPギャップ

| 項目 | 値 |
|---|---|
| 推計日 | 2026年11月6日（毎月勤労統計 9月速報の公表日） |
| 対象 | 内閣府「GDPギャップ」2026年7-9月期（1次QE後の公表値） |
| **推計値（推奨：公表値への接続値）** | **+0.58%** |
| 　内訳 | 2026年4-6月期の公表値 +0.7% ＋ モデルの前期→当期の変化幅 −0.12pt |
| モデル水準（参考） | +1.08% |
| 潜在成長率（前年比） | 0.52% |
| GDPの前提 | 実質GDP 7-9月期 前期比年率 +0.08%（ESPフォーキャスト2026年10月調査〈日本経済研究センター、10月14日公表〉の総平均） |
| GDP前提への感応度 | 前期比年率が1%ずれるとギャップは約0.24pt動く（年率−2%で+0.07%、+2%で+1.05%） |

## 使った統計（いずれも2026年11月6日時点の公表値）
- 労働力調査・一般職業紹介状況（9月分、10/30公表）
- 鉱工業指数 9月速報（10/30公表）
- 毎月勤労統計 9月速報（11/6公表）
- 日銀短観 9月調査（10/1公表）
- 固定資本ストック速報 4-6月期（9/30公表）
- 第3次産業活動指数：9月分は未公表（11/17公表予定）のため、7-8月の平均で補完

## 答え合わせの予定
- 11/16 GDP 1次速報（実績のGDPで推計し直す）
- 11月下旬〜12月初め 内閣府の公表値

## 手法
`nowcast_gdp_gap.py`（このリポジトリ）。内閣府 DP/26-8（並木 2026）の生産関数アプローチを再現したモデルで前期→当期の変化幅を出し、前期の公表値に接続する。2025Q2〜2026Q2の1次QE 5回のリアルタイム検証で、誤差（RMSE）は0.16pt。

再現コマンド：
```
python nowcast_gdp_gap.py --end 2026Q3 --gdp-saar 0.08 --source "ESPフォーキャスト2026年10月調査"
```
