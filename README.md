# gapmodel — 内閣府GDPギャップ・日銀需給ギャップの再現

## 推計の実行（推奨設定）

```
python estimate_gdp_gap.py  --end 2026Q2      # 内閣府GDPギャップ → results/gdp_gap_2026Q2.xlsx
python estimate_boj_gap.py  --end 2026Q2      # 日銀 需給ギャップ → results/boj_gap_2026Q2.xlsx
python nowcast_gdp_gap.py --end 2026Q3 --gdp-saar 0.08 --source "ESP10月調査"   # GDP速報前の超早期推計
python run.py                                 # 全期間の照合・図（results/）
```

- 内閣府：推奨値は「公表値への接続値」＝前期の公表GDPギャップ＋モデルの前期→当期の変化幅。モデルは前期差をRMSE 0.045ptで再現する一方、水準は期間により±0.5ptずれるため。2026Q2：接続値0.74（公表0.7）、モデル水準1.28。
- 日銀：推奨値はモデル水準（前期差RMSE 0.15pt、水準RMSE 0.21ptで接続の利点が小さい）。欠員補正は対象期の前期までの公表V/U比を使う（速報時点で使える情報のみ）。2026Q2：0.54（公表0.550）。
- 新しい期を推計するときは data/raw の各ファイルを更新する（形式はファイル先頭のコメント参照、取得先は `data_sources.xlsx`）。対象期をカバーしていない入力は「入力の到達状況」シートに×で表示される。
- 検証はいずれも最新ヴィンテージ同士の比較。速報時点では前期の公表値・GDPも改定されるため、実際の誤差はこれより大きくなりうる。

## データの更新（自動取得）

```
pip install -r requirements.txt     # 初回だけ
python update_data.py --dry-run     # 取得・解析・差分の確認だけ
python update_data.py               # data/raw に反映（更新前のコピーを data/backup/ に残す）
python update_data.py --only gdp    # 1次QE当日など、一部だけ
```

- 取得先は、URLが変わらない一覧ページからリンクをたどって見つける（ファイル名・統計IDが変わっても追える）。Python標準の urllib で取得するので、ブラウザ操作は要らない。
- 取得したファイルは `downloads/<日時>/` に、GDP速報CSVは `data/vintages/esri/` にも保存する（公表時点ごとの記録）。
- 報告（`downloads/<日時>/update_report.txt`）で、系列ごとに最終期の前後・新しい期の数・重なる期間の改定を確認する。「要確認」に出るのは、重なる期間の大きな改定、新しい期の大きな変化（原系列は前年同月比の動き）、既存より古いファイル。
- 反映するもの：GDP速報（実質季調）、鉱工業（生産・能力・稼働率）、第3次産業活動指数、毎勤 第8表（総実労働時間・常用雇用）と出勤日数、労調 1-a-1 と性・年齢別、一般職業紹介状況（表6・表8）、固定資本ストック速報、短観DI（日銀API）、内閣府の公表値（今週の指標PDF → `cao_vintages_raw.txt` と `cao_q_raw.txt` のGDPギャップ列）。いずれも既存データと全期間一致を確認済み（2026-11-06、Windows の Python 3.12 で実行）。
- `--only` に使える名前：gdp, iip, ita, mk, lfs, stock, tankan, lfs_sexage, mk_days, cao_pub, pesa。
- 手入力のまま：労調の就業時間（e-Statデータベース）、生産QNA、ESP、毎勤の製造業常用雇用（季調指数。推計では直近値で補う）、年次推計の2ファイル（ストックマトリックス・労働分配率）。
- 経産省の一覧ページが一時的にリンクを返さないことがあったため、鉱工業・第3次産業は固定URLに切り替える。取得した一覧ページは `downloads/<日時>/page_*.html` に残る。
- Claudeの作業環境（とPC内の作業用Linux環境）からは政府サイトに届かないので、取得は必ずWindows側で実行する。
- 実装は `gapmodel/ingest.py`（取得・解析・反映）と `update_data.py`（統計ごとの手順）。

依存：pandas, numpy, statsmodels, matplotlib, openpyxl, holidays（図の日本語には Noto Sans CJK）。

```
estimate_gdp_gap.py  内閣府GDPギャップの推計（Excel出力）
estimate_boj_gap.py  日銀 需給ギャップの推計（Excel出力）
data_sources.xlsx    算出に必要な統計・公表日時・リンク・早期化の余地（sources.json から tools_build_sources_xlsx.py で生成）
gapmodel/
  report.py   入力の到達状況チェック、公表値への接続、Excel出力
  config.py   推計上の「決め」をすべてここに集約（CAOConfig / BOJConfig）
  data.py     data/raw・data/published のキャッシュ読込
  tools.py    HP、STL季調、ウォートン・スクール法、区分線形トレンド、UV分析(GLS AR(1))、比率補間
  capital.py  固定資本ストック速報の分割（製造業有形／非製造業有形＋公的企業／無形）
  cao.py      内閣府（DP/26-8 並木2026）
  boj.py      日銀（川本ほか2017＋2026年改定）
run.py        実行・照合・図
results/      cao_replication.csv, boj_replication.csv, cao_sensitivity_breaks.csv, summary.json, replication.png
```

## データ（data/raw、2026-10-27取得）
- 実質GDP：2026年4–6月期2次QE（季調、連鎖）
- 固定資本ストック速報（内閣府、2026Q1まで）、2024年度年次推計 付表4 固定資本ストックマトリックス
- 労働分配率：2024年度年次推計（雇用者報酬・営業余剰・混合所得）
- 鉱工業指数（2020年基準、生産・生産能力・稼働率）、第3次産業活動指数（経産省）
- 短観 生産・営業用設備判断DI、雇用人員判断DI（日銀 時系列統計 API db=CO）
- 労働力調査（季調値、性年齢別 労働力人口比率・人口、表2-8-4 非農林業 平均週間就業時間）、毎月勤労統計（季調指数）、一般職業紹介状況（季調値）
- 毎勤 出勤日数（長期時系列表 実数・指数累積データ、調査産業計、5人以上／30人以上）
- 生産QNA（2026年1–3月期版、日銀10/5公表時点で利用可能だったもの）
- 公表値：内閣府 GDPギャップ・潜在成長率、日銀 需給ギャップ・潜在成長率・UV関連（data/published）

各ファイル先頭のコメントに e-Stat statInfId や元ファイル名を記載。経産省の一部ファイル（2017年以前の季調済み接続指数、第3次産業の原指数接続）は自動取得できなかったため、STL季調と季節係数による逆算で代替している。
